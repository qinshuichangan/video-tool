# 剪辑转换（iOS 侧载用）

在 iPhone 上截取视频、把视频转成音频的小工具，全部在手机上处理，不联网。

## 功能
- **截取视频**：直接输入开始 / 结束时间（`83.5`、`1:23`、`1:02:03.5`、`1分23秒` 都行），
  也可以边播放边点 ⌖ 把当前位置填进去；可以「试播这一段」确认
  - 快速模式：不重新编码，几秒完成、画质无损
  - 精确剪切：重新编码，切点精确到帧
- **转成音频**：AAC（.m4a）、AAC（.aac）、MP3、OGG（Vorbis），码率 96～320 kbps 可选；
  同样可以只转选中的那一段
- **压缩视频**：分辨率（原始 / 1080p / 720p / 540p / 480p / 360p）、帧率（原始 / 60 / 30 / 25 / 24 / 15）、
  码率（0.3～20 Mbps）都能调，编码可选 HEVC（更小）或 H.264（兼容性好），会显示预计大小；
  也可以只压缩选中的那一段
  - **网课(给AI)**：专门压给 Claude 看：480p / 每秒 1 帧 / 约 0.1 Mbps，声音单声道 32 kbps，一小时约 60 MB
  - **目标大小**：输入想要的 MB，自动算码率并挑合适的分辨率和帧率
  - **手动**：自己调分辨率、帧率、码率
- **分割**：处理完自动切成几段，方便一段一段上传
  - 每 X 分钟一段（最后剩下不到 10 秒会并到前一段），或者平均分成 X 段（最多 99 段）
  - 和所有格式都能一起用：选「视频（MP4）」就是不重新编码的无损分割；选「压缩视频」就是压缩后自动分割；选音频就是转换后分割
  - 文件名后面加「_第1段」「_第2段」…（10 段以上补 0），按名字排序就是顺序；会显示每段多长、预计多大
- **批量处理**：左上角「批量」，从相册或「文件」多选，排成队列用同一套设置一个个处理（整段，不剪；可以分割）
- **处理时屏幕调到最暗**：开关打开后，处理完之前不自动锁屏，结束后恢复亮度
- **后台继续**（iOS 26 起）：切到别的 App 也能接着处理，锁屏 / 灵动岛显示进度；被系统暂停的批量任务回到 App 后自动接着做
- 文件来源：相册，或「文件」App（也能选 yt-d 下载的视频：我的 iPhone → 视频下载）
- 从剪贴板直接粘贴音频 / 视频（点「粘贴」按钮，不会弹出允许粘贴的提示）
- 剪好的音频 / 视频可以一键复制到剪贴板，去微信、LINE 等直接粘贴
- 在「文件」App 里对视频/音频点「分享」→ 选「剪辑转换」也能直接打开
- 结果可以分享、存到相册，也会出现在「文件」App →「我的 iPhone」→「剪辑转换」

## 安卓版（APK）
`android/` 文件夹里是功能一样的安卓版（Android 10 以上）。推送后 GitHub Actions 的 **Build APK** 会自动编译，
在 Artifacts 下载 `VideoTool-apk`，解压得到 `VideoTool.apk` 直接安装。没有设置签名 Secrets 时用临时签名，更新前要先卸载旧版（打开「处理完自动存到相册 / 音乐」后，导出的文件卸载后也还在）。
安卓版切到别的 App 或锁屏也会继续处理，通知栏显示进度。MP3 / OGG 编码和 iPhone 版共用 `Codecs/`、`Vendor/` 的源码。

## 编译 IPA（不需要 Mac）
1. 把这个仓库的全部内容（包括 `.github` 文件夹）放到 GitHub 上。
2. 打开仓库的 **Actions** 页面，选 **Build IPA** → **Run workflow**（推送到 main 也会自动编译）。
3. 大约 5～10 分钟后，点进完成的那次运行，在页面底部 **Artifacts** 下载 `VideoTool-ipa`，解压得到 `VideoTool.ipa`。
4. 用平时的侧载工具（Sideloadly / AltStore / SideStore / TrollStore 等）安装。

## 用到的开源库
- MP3 编码：[LAME](https://lame.sourceforge.io/)（LGPL），源码在 `Vendor/lame`
- OGG 编码：[libogg / libvorbis](https://xiph.org/)（BSD），源码在 `Vendor/ogg`、`Vendor/vorbis`
- AAC 用的是 iPhone 系统自带的编码器
- `Codecs/AudioEncoders.c` 是给 Swift 调用的简单封装

## 版本号规则
- 修 bug：+0.01（例：1.03 → 1.04）
- 加功能：+0.1（例：1.03 → 1.13）
- 版本号在 `project.yml` 的 `CFBundleShortVersionString`，`CFBundleVersion` 每次 +1
- App 首页底部会显示当前版本
